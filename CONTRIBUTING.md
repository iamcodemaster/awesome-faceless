# Contribution Guidelines

Thank you for your interest in contributing to Awesome Faceless Content Creation!

## How to Contribute

### Adding a New Tool

1. Fork this repository
2. Add your tool to the appropriate category in `README.md`
3. Follow this format:

```markdown
| [Tool Name](https://toolwebsite.com/) | Brief description (under 60 chars) | Pricing | [Review](https://faceless.directory/directory/tool-slug) |
```

4. Submit a pull request

### Requirements

- **Relevance**: Tool must be useful for faceless content creation
- **Quality**: Tool should be actively maintained and functional
- **No duplicates**: Check if the tool already exists
- **Working links**: All links must be valid

### What We Accept

✅ AI tools for content creation  
✅ Video editing software  
✅ Voice/TTS generators  
✅ Automation tools  
✅ Analytics platforms  
✅ Free resources and guides  

### What We Don't Accept

❌ Paid courses or coaching  
❌ Tools with no free tier AND under $100/mo  
❌ Self-promotional spam  
❌ Affiliate-only links  

## Code of Conduct

Be respectful and constructive. We're all here to help creators succeed.

## Questions?

Open an issue or reach out via [faceless.directory](https://faceless.directory).
